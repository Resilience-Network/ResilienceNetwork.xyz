D1. Session authorization V1#

Principles. Authorization is deterministic, bounded, non-programmable and visible to consensus. One value has exactly one encoding. Worst-case work is charged before expensive work starts. New authority is delayed, while revocation takes effect as soon as it is finalized. Root, session, validator and network keys stay separate roles.

D2. Genesis-native formats#

Decision. Reject incompatible state instead of rewriting identity or inferring missing fields. Historical manifests, metadata rewriting and share-less staking interpretations were removed. A semantic change requires a coordinated fresh genesis; a restart on the same protocol reuses existing data and signing records.

Cost. No in-place upgrades during development. Upgrades after a production genesis will need explicit migration specifications.

D3. Unbiasable randomness beacon#

Proposed

Problem. Today's beacon is the winning proposer's VRF output. A winner who dislikes its output can withhold the block and get one retry, which turns a fair coin into a 3/4 coin. Contracts therefore must not read the beacon, and an EVM randomness precompile stays blocked.

Proposal. A threshold beacon with t = f + 1 of n = 3f + 1, to be built as threshold BLS with distributed key generation. Any t shares reconstruct the same output, so a Byzantine minority has no alternative to steer toward. Fewer than t shares reveal nothing about it.

Status. A prototype uses Shamir sharing over the Mersenne field 2127 − 1 and proves uniqueness, hiding and quorum agreement. Nothing in consensus imports it yet; key generation, share authentication and transport remain.

D4. ECRecover at 9,000 gas#

Context. Recovery in pure Go costs about 184 µs. At Ethereum's 3,000 gas, a block full of recoveries burns about 1.8 s of a 2 s slot, leaving no time for gossip, signatures or commit.

Decision. Price it at 9,000 gas, so a saturated block costs about 0.61 s. Output and success behavior stay identical to go-ethereum; only the price differs. Manifest revision 24.

Rejected. Halving the block gas limit, which penalizes every workload; per-attempt pricing, which adds consensus surface for no measured benefit; keeping 3,000 gas, which risks missed slots.

D5. SELFDESTRUCT sweeps only#

Decision. SELFDESTRUCT moves the contract's full balance to the beneficiary and halts. Code, storage, nonce and the account always survive, even for a contract created in the same transaction.

Rejected. Pre-Cancun full deletion, which Ethereum itself abandoned and which would need a new deletion primitive in state. EIP-6780 same-transaction deletion, which needs the same machinery and state-root churn, and imports Cancun semantics onto a Shanghai opcode surface for one narrow edge case.

D6. Plaintext mempool, disclosed#

Decision. Pending transactions stay readable by any peer, and block ordering stays a local convention: control transactions first, then nonce-sequenced fee priority. Integrators are told to use slippage bounds, deadline heights and private submission where available, and never to put secrets in calldata.

Deferred. A threshold-encrypted mempool and commit-reveal ordering; each needs its own protocol proposal. Rejected. A consensus-enforced ordering rule, which would turn benign deviations into faults without stopping a Byzantine proposer.

D7. Anchor-authenticated peer sampling#

Proposed

Problem. A node that loses its anchors has no other way to find peers on the open internet.

Decision. Connected anchors that passed the compatibility handshake may refer up to 16 live peers each, at most two per subnet, leased for one hour. There is no DNS, no transitive referral and no persistent referral cache. This is bounded sampling, not a claim of Sybil resistance.
