Known Limits

Current honest constraints
// LIMIT 01 — CONSENSUS LIVENESS UNDER LOAD

Sustained throughput is capped at ≤20 TPS (mixed transfers/calls) until the finality-halt failure tracked in issue #210 is root-caused and fixed. See the load qualification for the full cliff profile.

// LIMIT 02 — SHIELDED ACTIVITY IS EXPERIMENTAL

Orchard shielded transfers require a native cgo build with the Rust cryptography statically linked, an explicit experimental acknowledgment, and a trusted RPC for wallet scanning. Bulk historical sync is hash-bound. Builds with CGO_ENABLED=0 cannot process shielded activity at all.

// LIMIT 03 — PRE-MAINNET SOFTWARE

There is no mainnet. Development geneses (chain 1337) must match across participating nodes; protocol commitments change with the protocol. No result on this site is a release certification.

// LIMIT 04 — NO EXTERNAL QUALIFICATION YET

Independent external cryptographic qualification has not happened. It remains a hard release gate — which is exactly why it is listed here instead of implied away.
